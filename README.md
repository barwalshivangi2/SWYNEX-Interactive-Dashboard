# SWYNEX-Interactive-Dashboard
This repository contains Task 3 for my internship at SWYNEX Technologies. To push my boundaries beyond standard BI tools, I utilized Python and Streamlit to build a premium, fully customized interactive web dashboard using the analyzed Titanic dataset.

Dashboard Features:

Custom UI/UX: Implemented Custom CSS for a dark-themed, premium interface with gradient typography and 3D metric cards.

Dynamic KPIs: Real-time metrics including Total Passengers, Total Survived, and an aggregated Survival Rate percentage.

Interactive Visualizations: Clean, transparent Plotly-based Donut and Bar charts illustrating survival shares by gender and passenger class.

Filters: Dynamic sidebar slicer for 'Embarked' locations to explore real-time data.

Tools & Tech Stack: Python, Streamlit, Pandas, Plotly, Custom HTML/CSS
